# bdqnghi.github.io

Personal academic website for Dr. Nghi D. Q. Bui.

## Architecture

This repository is source-first:

- `src/` is the React and TypeScript application source.
- `public/` contains static assets copied into the production build.
- `index.html` is the Vite source entry and must load `/src/main.tsx`.
- `dist/` is generated by `npm run build` and must not be edited manually.
- Root `assets/` files are legacy GitHub Pages output and are not source.

See `README.md` for development, validation, and deployment instructions.

## Important files

- Home and Research Focus: `src/pages/Index.tsx`
- Publications: `src/data/publications.ts`
- Sidebar, visitor map, and navigation: `src/components/AppSidebar.tsx`
- Desktop and mobile layout: `src/components/Layout.tsx`
- Community highlights: `src/components/XTweetPanel.tsx`
- Static favicons and profile image: `public/`

## Commands

```bash
npm install
npm run dev
npm run build
npm run preview
```

Never replace the source `index.html` with `dist/index.html`. Production
deployment should publish `dist/` through GitHub Pages automation.
